# 🚀 Space Exploration Quiz

A fun and interactive quiz application about space exploration, planets, and astronomy. Test your cosmic knowledge with 10 challenging questions!

## 📋 About

**Space Explorer** is a lightweight, single-page web application that presents users with an engaging 10-question quiz about space, astronomy, and space exploration. The app features:

- 🎨 Beautiful gradient UI with dark mode support
- ⚡ Fast loading (no external dependencies)
- 📱 Fully responsive design
- ✅ Instant feedback on answers
- 🎯 Progress tracking
- 🏆 Performance-based result messages

## 🚀 Getting Started

### Local Installation & Running

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SlowWanderer/space-quiz.git
   cd space-quiz
   ```

2. **Open in your browser:**
   - Simply double-click `index.html`, or
   - Drag `index.html` into your browser, or
   - Use a local server (recommended):
     ```bash
     # Using Python 3
     python -m http.server 8000
     
     # Using Node.js (npx)
     npx http-server
     
     # Using Python 2
     python -m SimpleHTTPServer 8000
     ```
   - Then open `http://localhost:8000` in your browser

### No Installation Required

You can open `index.html` directly in any modern web browser without any setup or server. The app works completely offline!

## 🎮 How to Play

1. Open the application in your browser
2. Read each question carefully
3. Click on one of the four answer options
4. Receive instant feedback (correct/incorrect)
5. Progress through all 10 questions using the Previous/Next buttons
6. View your final score and performance message

## 📝 FAQ

**Q: Do I need internet to run this?**
A: No, the app works completely offline.

**Q: Can I save my score?**
A: No, but you can take the quiz multiple times to improve your performance.

**Q: Is there a time limit?**
A: No, you can take as much time as you need for each question.

**Q: Can I change my answer after selecting?**
A: Once selected, your answer is locked. You can restart the quiz to try again.

**Q: Does it work on mobile devices?**
A: Yes! The app is fully responsive and works on all screen sizes.
